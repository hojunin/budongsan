# 데이터 사전

<p class="lead">이 사이트의 숫자가 어디서 왔고, 무엇을 조심해야 하는지 정리합니다.</p>

## 출처

| 데이터 | 출처 | 갱신 | 범위 |
| --- | --- | --- | --- |
| 아파트 매매 실거래 | [국토교통부 실거래가 상세 API](https://www.data.go.kr/en/data/15126468/openapi.do) | 월 1회 (최근 3개월은 매번 다시 받음) | 서울 25개 구 + 경기 전체 시군구, 최근 36개월 |
| 아파트 전월세 실거래 | 국토교통부 전월세 API | 월 1회 | 관심 단지가 있는 시군구 |
| KB 지표 | [KB부동산 데이터허브](https://wooiljeong.github.io/python/pdr-kbland) (PublicDataReader) | 월 1회 | 서울·경기 월간 |
| 호가 | 네이버 부동산 화면을 보고 `src/data/listings.csv` 에 직접 기록 | 주 1회 권장 | 관심 단지만 |

## 지표 정의

| 지표 | 계산 |
| --- | --- |
| 거래량 | 계약월 기준 정상 거래 건수. 해제 거래는 따로 표시 |
| ㎡당 중위가 | 거래금액 ÷ 전용면적의 월별 중위값 (만 원/㎡) |
| 신고가 비율 | 같은 단지·평형의 직전 최고가(해제 제외)를 넘은 거래의 비율 |
| 해제율·직거래율 | 전체 거래 중 해제 신고, 중개 없는 직거래의 비율 |
| 전세가율 | 최근 3개월 전세 보증금 중위 ÷ 최근 3개월 매매 중위 |
| 호가 괴리율 | 기록한 호가 중위 ÷ 최근 3개월 실거래 중위 − 1 |

## 알려진 한계

- 실거래는 계약 후 신고가 늦게 들어와서 최근 1개월이 적게 잡힙니다. 추세 계산에서는 빼고 봅니다.
- 단지명 표기가 데이터마다 달라서, 관심 단지는 시군구 + 단지명 일부(`match`)로 찾습니다. 다른 단지가 섞이면 `watchlist.json`의 `match`를 더 길게 적으세요.
- KB 데이터는 공식 API가 아닌 공개 웹 데이터를 읽습니다. 응답 형식이 바뀌면 수집이 멈추고, 마지막 캐시를 그대로 씁니다.
- 네이버 부동산은 자동 수집하지 않습니다. 동의 없는 대량 수집이 위법으로 판단된 사례가 있어서, 수기 기록만 지원합니다.
- 화면에 ‘샘플 데이터’ 배너가 뜨면 인증키 없이 빌드된 가짜 숫자입니다.
