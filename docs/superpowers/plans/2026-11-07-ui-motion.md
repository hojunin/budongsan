# Responsive dashboard implementation plan

Goal: Apply the approved financial dashboard design, a small UI library and Motion, with mobile as a required baseline.

Architecture: Keep Observable Inputs, queries and Plot. Import Chota CSS from the installed package; share visual tokens across the framework. A disposable Motion mini observer animates new cards and chart replacements, respecting reduced motion.

- [x] Style: import Chota; align typography, navigation, filter fields, cards and tables in src/style.css. Keep light/dark support and visible focus. Mobile filters stack; tables scroll within containers.
- [x] Motion: add src/components/appearance.js, start with an independent reactive cell on all six pages, disconnect observers and cancel animations on invalidation.
- [x] Verify: production build; browser check all pages at desktop and 390px, plus 320px overflow, filter updates, keyboard focus and reduced motion.

Scope: package manifests, common stylesheet, appearance module, six Markdown pages. No financial logic, data, queries or exports change. Chota replaces the proposed Pico because Pico's official documentation announces maintenance has ended. Avoid an icon dependency without a concrete need.

Verification: npm run build passed; node scripts/check_ui.mjs passed all 18 page/viewport combinations (320, 390, 1440px). Browser checks confirmed loan-rate updates, Motion start/cancel/disposal, reduced motion, dark mode and visible keyboard focus. Physical iOS/Android devices were not tested.
