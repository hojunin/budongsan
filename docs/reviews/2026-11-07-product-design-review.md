# 제품 디자인 리뷰 — 3인 종합안

2026-11-07 · Senior Product Designer 관점의 독립 3인 리뷰. 배포 화면을 desktop 1440px, mobile 390px 중심으로 확인하고 일부 320px 화면과 소스를 검사했다. 이번 작업은 숫자 표시 구현과 디자인 리뷰까지다. 아래 디자인 시스템과 화면 재구성은 아직 적용하거나 배포하지 않았다.

## 결정 제안

**차분한 데이터 제품: Slate 중립색 + Teal 대표색.** 글자를 작게 만들어 밀도를 높이는 대신, 기본 화면에서 묻는 질문과 표시하는 정보를 줄인다. 제목 → 핵심 값 → 비교 기간·단위 → 근거 순서로 읽히게 한다. 현재 라이브러리와 설명 팝오버를 재사용하고 새 UI 라이브러리를 추가하지 않는다.

날짜 epoch 노출은 이번 숫자 작업에서 사람이 읽는 날짜로 변환했다. 최신 월의 잠정치 표시는 별도 디자인 적용 대상이다.

## 문구를 줄이는 기준

| 그대로 보여줄 정보 | 정보 아이콘/인터랙션으로 옮길 정보 | 삭제하거나 운영 문서로 옮길 정보 |
|---|---|---|
| 값·단위·기준일·비교 기간·표본수 | 중위가·분위수·지수의 정의와 집계법 | 파일 경로, 캐시, 빌드·배포 명령 |
| 잠정치·샘플 여부·데이터 없음 | 점/선·분포 띠의 읽는 법 | 범례를 그대로 반복하는 하단 장문 |
| 대출 계산의 주요 가정·제외 비용 | 상세 계산식·수집 경로 | 매 페이지의 중복 DATA DESK 소개 |
| 선택 필터·초기화·표시 결과수 | 부차 필터는 ‘상세 조건’ 펼침 | 근거 없이 매도자 우위/이상 거래를 단정하는 해설 |

예시: `listings.csv 에 호가를 적으면 계산` → `등록된 호가 없음`. `기사 목록 — 378건` → `검색 결과 378건 · 최신 150건 표시`. `B · 상계주공16단지` → `상계주공16단지`. 메타포는 보조로만 사용하며 정확한 지표명·단위를 대체하지 않는다. 아이콘 단독 버튼에는 읽을 수 있는 이름이 필요하다.

기존 설명 버튼은 재사용한다. 모바일에서 패널 표시가 확인된 사례와 클릭 후 닫힌 사례가 함께 있어 hover→click 전환을 재검증해야 한다. hover 전용으로 만들지 않고 터치·Enter/Space·Escape·바깥 클릭을 함께 보장한다.

대표색은 선택·조작에 집중하고 카테고리 칩은 중립색으로 한다. 상승/하락에는 부호·문자도 병용한다. 비교 차트는 서울 Indigo, 경기 Cyan, 수도권 Amber, 전국 Slate로 고정하고 선형/마커를 병용한다. 상세 hex와 light/dark 매핑은 컬러 리뷰에 있다. 제안 action/white 대비는 5.47:1, meta/white는 4.76:1이다. 실제 hover·disabled·투명도 조합은 별도 검증한다.

| 요소 | Desktop | Mobile |
|---|---|---|
| H1 | 32px / 40px | 28px / 36px |
| 섹션 제목 | 18px / 26px | 16px / 24px |
| 본문 | 15px / 24px | 14–16px / 22–26px |
| KPI 값 | 28–32px | 24–28px |
| 라벨·필수 설명 | 13–14px | 13–14px |
| 표 | 14px | 13–14px |
| 축·범례 / 툴팁 | 12–13px / 14px | 12–13px / 14px |

Pretendard와 tabular-nums를 유지한다. 입력 글씨는 16px로 iOS 자동 확대를 피한다. 간격은 4/8/12/16/24/32/48px, 카드 padding desktop24/mobile16px. radius는 필드8/card12/pill999로 정리한다. 터치 영역44px 안에 작은 아이콘을 둬 시각 밀도를 유지한다. 포커스는 3px ring + 2px offset.

KPI 높이를 단순히 줄여 초기 로딩 CLS를 다시 만들면 안 된다. 모바일 152–168px는 시안 시작점이며, 긴 값·설명으로 검증해 초기 슬롯과 완료 상태가 같은 규격을 쓰게 한다. 표·차트 자리 예약도 유지한다.

## 구현 순서와 수용 기준

1. 색/글자 토큰과 의미색 분리 → 표 상세 접근성 및 지역색 고정.
2. 공용 KPI·필터·표·차트 글자/간격 적용 → 홈 요약, 뉴스 순서, 운영 문구 정리.
3. 320/390/1440px, light/dark, 긴 숫자·결측·음수에서 확인. 키보드로 표 상세와 차트 대안 사용. 설명 패널 화면 이탈 없음.
4. 초기 로딩·필터·칩 삭제의 모바일 CLS 재측정. 기존 자리 예약을 보존하고 변경 전후 수치를 비교한다.
