# 복합 인사이트 제품·편집 독립 검토

2026-11-07 · 검토 대상: `docs/insights/2026-11-07-composite-insights.md`, `docs/data/2026-11-07-interface-contract.md`.

**판정: 구매자·임차인·일반 독자에게 의미 있는 복합 관측 설계가 10개 이상 남는다. 그러나 현재 시장 결과나 출시 가능성을 검증한 것은 아니다.** E의 I01–I13만으로도 13개 독자 질문이 있다. I14는 운영·신뢰성 기능이므로 시장 인사이트 수에서 제외한다. N 여섯 개는 데이터 계약 검증 전 공개 보류다. I08/I15는 관측 시장 인사이트와 구분할 시나리오 도구다. 이를 엄격히 제외해도 E의 관측 질문은 12개이며, 서로 중복되는 I01/I02/I03을 한 묶음으로 세어도 10개다. 이는 콘텐츠 기획 수이지 지금 발행 가능한 기사 수가 아니다.

## 먼저 고칠 문제

1. **P1 — I08의 ‘월 현금 부담’ 제목이 계산과 다르다.** `R+D*r/12`에는 실제 지출하지 않는 자기자금 기회비용이 포함될 수 있다. 제목을 ‘보증금 가정에 따른 환산 월비용’으로 바꾸고, 첫 줄에 보증금·실제 납부 월세, 다음 줄에 ‘가정 연 r%의 환산값’을 둔다. 싼 순서 추천·절약액 배지는 붙이지 않는다. 현재 본문의 한계 문구만으로는 제목의 현금흐름 오해를 막지 못한다.
2. **P1 — 표본 정책의 우선순위가 모호하다.** 공통 계약은 ‘지역 비교/기간 변화 해당 셀 양쪽 n≥30’과 ‘모든 셀/층화/면적군마다 확인’을 요구하지만 I02/I07은 셀 n≥5를 허용한다. 제품별 예외인지 공통 게이트 위반인지 확정해야 같은 선택에서 카드가 일관되게 노출된다. ID별 최소표본·경고·차단 표 한 개로 고정하고, n5는 정밀한 분포나 순위의 근거가 아님을 화면에 명시한다.
3. **P1 — E/N 표시는 독자용 준비도 표시로 부적합하다.** E도 원값 검증·완결성·사용권·매칭이 안 되면 사용할 수 없다. 제작 목록에는 E/N을 유지해도 공개 카드에는 ‘관측 기간 / 잠정·정정 / 비교 가능·보류 이유’를 쓴다. 이번 검토로 어떤 API 응답이나 현재 수치도 승인하지 않는다.
4. **P2 — I12의 기간 문장이 틀릴 수 있다.** 기본 최근 완료 3개월은 역법상 분기와 다르지만 문장 템플릿은 ‘해당 분기’라고 한다. ‘{시작월}–{종료월} 실거래’로 바꾸고 공식 지수의 단일 월을 바로 옆에 표시한다. 왜 다른지의 원인을 확정한 듯한 목록 질문도 ‘어떤 조건이 다른가?’로 낮추는 편이 정확하다.
5. **P2 — 차트 문법을 확정하지 않으면 정량 오해가 남는다.** I17의 누적막대는 반드시 `준공 전 U−C / 준공 후 C`로 구성하고 합계 U를 라벨한다. I16은 착공→준공→임대의 화살표를 쓰면 동일 코호트·인과 흐름처럼 읽히므로 독립 패널을 유지한다. I06 연결선에는 ‘집단 차이’를 붙여 대출 필요액이나 보증금 안전여유처럼 보이지 않게 한다.
6. **P2 — 모바일에는 ‘작은 차트’의 구체 규칙이 필요하다.** 공통 메타·경고·그래픽을 한 카드에 모두 쌓으면 비교값이 화면 아래로 밀린다. 한 화면에서는 질문, 핵심 두 값, 기간·n·잠정 상태를 먼저 보여주고 상세 범위와 방법을 펼친다. 단위·핵심 제한은 펼침에 숨기지 않는다. 4분면/산점도(I01/I20)는 선택 항목의 텍스트 비교표를 기본 대안으로 두고, 동일 축 분포(I03/I09)는 모바일에서도 축을 공유한다. 범위 밖 예산선은 가장자리 고정선으로 위장하지 말고 방향과 실제 금액을 적는다.

## ID별 판정

여기서 ‘설계 적합’은 질문·표현 설계의 적합성이다. E도 실제 데이터·품질 게이트를 통과했다는 뜻이 아니다. ‘보류’는 신규 소스의 응답·항목·커버리지·이용권 미확정으로 공개를 보류한다는 뜻이다.

| ID | 판정 | 독자 결정 가치와 필요한 표현 |
|---|---|---|
| I01 | 설계 적합 | 지역 분위기를 가격 한 숫자로 판단하지 않게 한다. 4분면에 강세/약세·매수 적기 이름을 붙이지 않고 실제 건수도 직접 표시한다. |
| I02 | 조건부 | 상승이 거래 구성 때문인지 재확인할 가치가 크다. 매칭률과 탈락 표본을 두 변화량과 같은 위계로 표시하고 P1 표본 정책을 정리한다. |
| I03 | 설계 적합 | 중간값만으로 후보의 가격대를 짐작하는 오류를 줄인다. 상대 폭뿐 아니라 원금액 Q25/M/Q75를 읽을 수 있어야 한다. |
| I04 | 조건부 | 지역의 신고가 뉴스가 얼마나 넓은지 확인하는 일반 독자용 질문이다. 60개월 완결·비교 가능 거래 비중 없이는 보류, 순위·최고가 축하 연출 금지. |
| I05 | 설계 적합 | 실제 구매자의 면적 선택에 직접 도움. 표본이 적은 두 점을 확정 업그레이드 비용처럼 쓰지 않고 실제 면적 범위와 기간을 함께 표시한다. |
| I06 | 조건부 | 매매·전세 거래 집단의 가격 관계 확인에 유용. 원본 월세 0 검증이 선행하며 보증 안전성이나 매수 자금으로 번역하지 않는다. |
| I07 | 조건부 | 임차인에게 전체 월세 상승의 조건 변화를 설명한다. 구간별 보증금 범위·표본·구성비를 함께 읽히게 하고 표본 정책을 확정한다. |
| I08 | 조건부 | 임차인의 보증금 선택 가정을 비교하는 도구. 관측 시장 분석 수와 분리하고 P1 명칭을 수정한다. 가정 미입력은 결과 없음이 맞다. |
| I09 | 설계 적합 | 구매 후보를 좁히는 가장 직접적인 질문. ‘상한 이하 과거 거래 k/n’을 주요 문장으로 유지하고 현재 매물·구매확률처럼 표시하지 않는다. |
| I10 | 설계 적합 | 외부 거주자 비중 기사에서 분모 착시를 교정한다. 외지인·투기·이주 표현 대신 ‘다른 시도 거주자’와 전체 건수를 유지한다. |
| I11 | 설계 적합 | 연령별 비중 증가를 실제 구매 증가로 착각하지 않게 한다. ‘청년’ 단독 제목보다 실제 집계 연령을 제목·차트에 쓴다. |
| I12 | 조건부 | 서로 다른 가격 통계가 충돌해 보이는 이유를 독자가 점검한다. P2 기간 수정과 독립 패널이 필요하며 차이를 오류 판정으로 쓰지 않는다. |
| I13 | 설계 적합 | 가격 기사를 어떤 거래 정의로 읽어야 하는지 확인한다. 토글만 두면 기억 비교가 되므로 두 결과·n·유형미상을 동시에 유지한다. |
| I14 | 설계 적합·운영 | 모든 결과의 해석 가능 범위를 알려준다. 독립 시장 기사나 14번째 시장 인사이트로 계산하지 않는다. 실패와 성공 0건의 표현을 분리한다. |
| I15 | 보류 | 구매자의 대출 현금흐름 가정에 유용하나 시장 관측이 아니다. ECOS 항목·상환함수 검증 뒤, 원금 포함 상환액과 이자 비용을 구별한다. |
| I16 | 보류 | 임대시장과 공급의 배경을 병렬로 읽는 일반 독자용 관측. 완료 실적을 미래 입주나 임대료 하락 원인으로 시각화하지 않는다. |
| I17 | 보류 | 미분양 증가가 준공 후 재고와 함께 나타나는지 읽을 가치가 있다. 중복 없는 누적막대와 독립 준공 패널이 필요하다. |
| I18 | 보류 | 인구 감소=임대수요 감소라는 단정을 점검한다. 주민등록 세대·가구·거래를 혼용하지 않고 지표별 실제 기간을 붙인다. |
| I19 | 보류 | 청약과 기존 주택을 비교하려는 구매자에게 유용. 타입·층별 가격, 제외 비용, 비교 단지 선택을 우선 노출하고 차익·투자 매력 순위로 만들지 않는다. |
| I20 | 보류 | 규모가 다른 단지의 거래건수를 비교하는 구매자에게 유용. ‘회전율’ 옆에 ‘세대수 대비 거래건수’를 풀어 쓰고 유동성·매도 용이성 보장은 하지 않는다. |

## 발행 전 확인해야 할 제품 증거

매수 과제는 I09→I05→원 거래 확인, 임차 과제는 I08→I07→원 거래 확인으로 짧게 테스트한다. 참가자가 과거 거래를 현재 매물로, 환산비용을 실제 월 납부액으로, 집단 전세 비율을 안전 점수로 읽으면 문구와 위계를 수정한다. 브리핑 과제에서는 I10/I11의 비중 증가와 건수 감소를 동시에 설명할 수 있는지 확인한다.

모바일 화면·합성 fixture·실데이터·API·사용권은 확인하지 않았다. 남은 위험은 적은 표본, 거래 구성 차이, 원값 누락과 공급기관 정정이며 현재 설계 판정으로 제거되지 않는다.

## 수정 후 재검토 — 2026-11-07

카탈로그와 공통 계약의 수정 문구를 대조했다. 위 여섯 우선 문제는 **명세 수준에서 해소**됐다. I08은 실제 보증금/납부 월세와 가정 환산값을 분리했고, ID별 표본 정책에 우선순위가 생겼다. E/N의 내부 전용 표시, I12의 실제 관측기간, I17의 `(U−C)+C` 구성, 모바일 값·단위·비교표·공유축·범위 밖 표시, I06 집단 차이, I16 독립 패널도 명문화됐다. I07은 보증금 구간 내 원분포 이동까지 표시하며 같은 보증금의 인상으로 단정하지 않도록 보완됐다.

이 검토 범위에서 추가로 발행 설계를 막는 중대한 제품·편집 문제는 찾지 못했다. I02/I08/I12는 해당 표현 수정 조건을 충족했다. I04/I06의 이력·원값 조건과 N의 응답/단위/범위/사용권 보류는 계속 유효하다. 의미 있는 관측 설계 10개 이상이라는 최초 판단도 유지한다.

수정된 문서만 재검토했다. 화면 구현·모바일 사용자 과제·계산 fixture·실데이터·API 검증은 실행하지 않았으므로 실제 가독성과 데이터 발행 적합성을 승인한 결과는 아니다.
