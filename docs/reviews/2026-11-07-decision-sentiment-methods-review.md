# 개인 판단·심리·정책 확장 독립 방법론 검토

2026-11-07 · [가치 확장 설계 I21–I28](../superpowers/specs/2026-11-07-buyer-decisions-sentiment-policy-design.md)와 [후보 인터페이스 §7](../data/2026-11-07-candidate-interfaces.md#7-심리전망정책-반응-확장-소스)를 문서 대조했다. 실제 개인 재무·시장 전망·여론·정책효과를 검증한 결과가 아니다. 네트워크·코드 실행·DB·개인정보 접근 없이 설계만 검토했다.

## 수정할 발견사항

### P1 — I21의 월 현금 잔여는 세전소득을 그대로 사용할 수 없다

`월잔여=월소득−생활지출−기존상환−신규상환`에서 소득의 세전/세후를 선택하고 지출과 ‘같은 기준’으로 맞춘다는 문장만으로는 현금흐름이 일치하지 않는다. 생활비·대출상환은 실제 현금 지출이므로 세전소득을 쓰면 세금·사회보험만큼 가처분 현금을 과대 표시한다. 예를 들어 세전 500, 세금/보험 80, 생활비·상환 400이면 실제 잔여는 20인데 현재 식에 세전을 넣으면 100이다. 사용자의 ‘여유 기준 충족’까지 바뀔 수 있다.

**최소 수정:** 첫 버전 월소득은 `월 실수령소득(세후·사회보험 공제후)`만 받는다. 세전 입력을 유지하려면 세금/사회보험 공제액을 별도 필수 입력으로 받아 먼저 차감하고, 미입력이면 결과를 보류한다. 생활지출에는 기존/신규 대출상환이 포함되지 않는다고 정의해 이중 차감도 막는다. 금리 충격은 고정금리 계약의 실제 재가격을 뜻하지 않는다는 가정도 보존한다.

### P2 — I25 제목이 확인되지 않은 응답집단 분리를 약속한다

제목 ‘중개업소·일반가구·임차인이 느끼는 시장은 다른가?’는 서로 분리된 세 응답집단의 심리를 보여 준다는 뜻이다. 본문과 후보 계약은 정반대로 국토연구원 매매/전세가 시장부문이며 매수자/임차인 별도표본을 뜻하지 않는다고 올바르게 경고한다. 현재 확인 수준에서 임차인만의 결과를 뒷받침하는 계약은 없다. 본문 주석으로 제목의 오인을 해소하기 어렵다.

**최소 수정:** ‘조사 출처·문항에 따라 시장심리는 어떻게 다르게 보이나?’로 제목을 바꾸고, 각 패널 제목에는 검증된 실제 응답집단만 넣는다. 임차인 분리표본은 실제로 확인된 후 별도 추가한다. 서로 다른 지수 차이를 집단간 점수차로 계산하지 않는 기존 규칙은 유지한다.

### P2 — I27 복수선택 문항은 분자와 문항 분모를 명확히 정의해야 한다

현재 `응답 범주수/해당 문항 유효응답수`는 ‘선택된 범주의 수’인지 ‘그 선택지를 고른 응답자 수’인지 모호하다. 우려는 복수선택이므로 총 선택횟수를 분모로 쓰면 응답자 중 그 우려를 고른 비율과 다른 값이 된다. 역할 중복은 이미 경고했지만 문항 내부 복수선택의 합계가 100%를 넘을 수 있다는 규칙과 모름/무응답의 분모 처리가 빠졌다.

**최소 수정:** 단일선택은 `범주별 응답자수 / 해당 문항 유효 응답자수`, 복수선택은 `선택지별 고유 응답자수 / 해당 문항 유효 응답자수`로 고정한다. 한 사람이 같은 선택지를 여러 번 제출해도 문항 응답 단위에서 한 번만 센다. ‘모름/유보’는 명시 선택지로 분모에 포함하고 문항 미응답은 별도 수/비율로 보존한다. 복수선택의 ‘우려 없음/모름’은 다른 우려와 동시 선택되지 않도록 하고, `복수선택·합계100%초과 가능`을 표시한다. 가중 외부조사는 제공기관 가중 비율과 비가중 표본 n을 구분하며 사이트 응답과 합하지 않는다.

## ID별 판정

설계 적합은 운영 발행 승인이 아니다. 조건부는 계산/입력 정의를 보완하거나 필수 이력 조건이 필요함을, 보류는 필요한 신규 원천 계약을 확인하기 전 해당 조합을 제공할 수 없음을 뜻한다.

## 공통 확인 결과

시장 전망과 개인 감당 가능성을 분리하고, 근거 개수를 상승확률/점수로 바꾸지 않으며, 예측 기능에 별도 시계열 검증·확률보정 조건을 둔 것은 타당하다. 출처별 조사 대상·문항·기대기간·가중·지역을 보존하는 §7 메타데이터도 필요하다. 기관 지수의 100 기준을 통일된 심리 경계로 쓰지 않고 지수 p·응답비중 %·비중변화 %p를 구분해야 한다.

정책 전후 관측은 인과효과가 아니며 I27의 의견과 I28의 거래 변화는 서로를 검증하는 값도 아니다. 네이버 상대검색은 관심의 보조 자료로만 사용한다. 검색 증가·기사 증가를 불안/매수의향/정책 찬반으로 번역하지 않는 제한을 유지해야 한다.

미확인: 실제 응답·기존 상환함수·시장수치·예측 성능·설문 실행은 확인하지 않았다. 위험: 개인 현금흐름 기준 수정 전에는 ‘여유 기준 충족’ 결과를 제공하면 안 된다.

## 재검토 — 수정본 조치 확인

동일 날짜의 수정된 확장 설계를 대조했다. 최초 P1/P2 3건은 모두 **설계 문서 수준에서 조치 완료**다. I21은 세후 실수령액만 받고, 생활비·기존/신규 상환·매수후 주거유지비를 분리하며 불명확한 보증금 반환을 사용가능현금에서 제외한다. I25 제목은 출처·문항 비교로 바뀌어 검증되지 않은 임차인 별도표본을 약속하지 않는다. I27은 단일선택·복수선택 모두 문항별 유효 응답 레코드를 분모로 고정하고, 선택횟수 분모를 금지하며 모름/우려 없음의 배타성·무응답 분리·합계100%초과·고유인원 미검증을 명시했다. 응답 레코드와 사람수를 구별한 것은 익명 수집 한계에 맞다.

I22의 월 순저축·보증금 분리와 시점별 한 번의 출납도 확인했다. 역할 중복과 희소 조합/자유답변의 공개 제한이 추가되어 n30을 대표성·재식별 방지 보증으로 쓰지 않는다.

**남은 미해결 P1/P2 방법론 발견은 없다.** I21/I22는 위 입력 정의와 산술 검증을 구현할 조건이 남고, I23/I25/I26의 신규 조사 원천·범위·권리 보류는 계속 적용된다. 최초 표는 당시 발견 기록이며, I21의 세전소득 문제·I25 제목·I27 분모 문제는 위 재검토 결과로 해소됐다. 구현·실응답·실제 현금흐름 fixture는 이번에도 검증하지 않았으며 문서 조치 완료는 개인 판단이나 운영 발행 승인이 아니다.
