# 정보 구조·문구·인터랙션 리뷰

2026-11-07. 실제 배포 사이트를 agent-browser 독립 세션 `design-review-ia`로 확인. 홈 `/`, 실거래 `/trades`, 단지 `/complexes`, 뉴스 `/news`에서 1440×1000과 390×844를 확인했다. `/reports/`도 실제 텍스트 확인. 구현·배포·커밋 없음.

## 우선순위별 제안

### P1 — 홈은 20개 문장 대신 먼저 답할 질문 3개를 정한다

- 증거: `.kpis`의 서울 주간 +0.07%, 수급 109.4, 거래 3,441건, 84㎡ 10.5억이 아래 `.insight-list`에 다시 등장한다. 핵심 인사이트는 비뉴스 20개가 같은 크기·복사 버튼으로 이어진다. 390 화면에서 첫 문장이 가로로 길게 이어지고 복사 버튼이 화면 안에 드러나지 않는다.
- 변경: `가격은? / 거래는? / 어느 지역이 다른가?` 순으로 요약 3개를 먼저 보여 주고 각각 실거래·시장지표·지역비교로 연결한다. 나머지는 `인사이트 17개 더 보기`로 접는다. 데이터 자체는 삭제하지 않는다.
- before → after: `핵심 인사이트` → `서울: 가격은 오르고 거래는 줄었습니다` 아래 `주간 +0.07% · 9월 거래 전월 대비 -4%`. 기간이 다른 지표임을 문장에 남긴다. 이는 인과 해석을 추가하지 않는 병렬 요약이다.
- 표면: 결론·값·비교 기간·출처·기준일·복사. 팝오버: 집계법·신고 기한. 삭제: 동일 값의 두 번째 노출, `DB에 쌓인…매번 다시 계산` 같은 내부 과정 설명.

### P1 — 지표의 방향을 단정하는 해설은 중립적인 관측값으로 바꾼다

- 증거: `/trades` 보조지표 아래 `신고가 비율이 오르면 매도자 우위입니다. 해제·직거래 비율이 튀면 이상 거래를 의심해 볼 신호입니다.` 홈에는 부동산원 수급 109.4(수요 우위)와 KB 69.5(매도자 우위)가 다른 날짜로 함께 나온다.
- 변경: 해석의 확실성을 데이터보다 크게 표현하지 않는다. 충돌하는 공급자 지표는 각각 공급자·기준일을 붙여 비교한다.
- before → after: `신고가 비율이 오르면 매도자 우위입니다` → `선택 기간 거래 중 신고가 거래 비중`. `이상 거래를 의심` → `해제·직거래 비중이 달라진 구간을 확인하세요`.
- 표면: 비중과 기간, 해제 포함 여부. 팝오버: 신고가 정의·비교 표본의 차이. 삭제: 근거 없는 단정. 메타포를 쓰면 `시장 온도계` 한 단어만 보조로 쓰고 지표명을 대체하지 않는다.

### P1 — 공개 리포트와 운영자 작성 안내를 분리한다

- 증거: 홈의 `.note a[href='./reports/']`는 `내 리포트 쓰기 →`지만 도착 페이지는 `발행한 리포트 — 0편`, Python 명령, `git mv`, clean/build/deploy 절차다. 웹 작성 버튼/편집기는 없다. 단지 호가 KPI에도 `listings.csv 에 호가를 적으면 계산`이 표시된다.
- 변경: 공개 방문자 경로에서는 `시장 리포트 보기`로 명명하고 0편일 때는 홈 CTA를 숨긴다. 작성법은 운영 문서로 이동한다. 호가 미등록은 정확한 빈 상태로 표시한다.
- before → after: `내 리포트 쓰기 →` → `시장 리포트 보기 →`; `listings.csv 에 호가를 적으면 계산` → `등록된 호가 없음`.
- 표면: 발행 글·발행일·현재 데이터로 차트가 갱신된다는 사실. 팝오버: 글 작성일과 차트 기준일 차이. 삭제/운영문서 이동: 파일 경로·명령어·캐시 사정.

### P1 — 최신 월 잠정치와 기준일을 값 가까이 둔다

- 증거: `/trades` 첫 KPI `최근 월 거래량 1,819 / 2026-10 · 해제 32건`의 신고 미완료 주의는 차트 아래 문장 끝에 있다. 페이지 끝은 `마지막 거래일: 1793923200000.`으로 노출된다. 홈 월 거래는 9월, 실거래 화면은 10월을 써 페이지 간 비교시 오해 가능하다.
- 변경: KPI에 `10월 거래 1,819건 · 잠정`을 붙이고 정보 버튼에 신고 지연 설명. 날짜는 사람이 읽는 한국어 날짜로 표시한다.
- before → after: `마지막 거래일: 1793923200000` → 날짜를 실제 변환한 `마지막 계약일: YYYY.MM.DD`. 숫자를 추측해 문구에 고정하지 않는다.
- 표면: 단위 건·기준월·잠정 배지·표본수. 팝오버: 신고 30일과 취소 반영 방식. 삭제: 같은 안내의 반복. 이 항목은 문구 교체만으로 끝내지 말고 날짜 포맷 경로를 수정할 필요가 있다.

### P2 — 뉴스는 목록을 먼저, 통계는 선택해서 본다

- 증거: `/news`의 `.card.grid-1` 기사 목록은 desktop 문서 y=881부터 시작한다. mobile 첫 화면은 긴 소개·4개 필터·주제어 카드의 시작까지만 보이고, 기사에 도달하려면 주제어 차트와 언론사 차트를 지나야 한다. 제목은 `기사 목록 — 378건`이나 실제 렌더는 코드에서 150개로 제한된다. 제한 설명은 정보 버튼 안에 있다.
- 변경: 필터 → `378건 중 최신 150건` 목록 → `기사 흐름 보기` 접이 영역 순서. 검색 결과를 읽는 행동이 먼저다. 주제어 칩은 클릭해 검색을 적용할 때만 버튼 외형을 준다(현재는 span).
- before → after: 긴 `.lead` → `최근 부동산 기사와 시장 동향을 찾아봅니다.`; `기사 목록 — 378건` → `검색 결과 378건 · 최신 150건 표시`.
- 표면: 결과수·표시수·제목·매체·발행일·원문 이동 표시. 팝오버: 수집 경로·주제어 중복 집계. 삭제: 저작권 때문에 제목만 보인다는 변명형 문장(수집 정책에 한 번만 안내).

### P2 — 단지는 단지명 → 면적 → 가격 순으로 한 덩어리로 묶는다

- 증거: `/complexes`는 찾는 방법 → 단지 선택 → 독립 평형 필터 → 아래 단지명 `상계주공16단지 B 트랙 · 7호선 마들 · 성수 40~45분` → KPI 순이다. 처음 온 사용자는 B 트랙의 의미를 알 수 없다. `관심 단지`도 사용자 저장 목록처럼 읽히지만 제공된 watchlist다.
- 변경: 헤더를 `상계주공16단지 / 59㎡대`로 묶고 면적을 바로 변경할 수 있게 한다. 찾는 방법은 `추천 목록 / 단지 검색`, 트랙 코드는 공개 설명이 없으면 제거한다.
- before → after: `타겟 단지` → `단지 살펴보기`; `B · 상계주공16단지` → `상계주공16단지`; `최근 3개월 중위 실거래` → `최근 거래 중간값 · 3개월`.
- 표면: 단지·면적·거래 기간·표본 8건·가격·역/통근 정보가 실제 사용 목적이면 유지. 팝오버: 중위가 정의·호가 괴리율 계산식. 삭제: 미정의 A/B 코드와 파일 편집 안내.

### P2 — 설명 아이콘은 기존 details를 재사용하되 핵심 정보까지 숨기지 않는다

- 증거: `src/components/ui.js heading()`는 이미 `<details class='chart-info'><summary aria-label='… 설명'>` 구조를 쓴다. 뉴스 390 화면에서 설명 버튼 클릭을 실행했다. 클릭 후 native details.open은 false였으므로 실제 패널 표시 상태를 통과로 판정하지 않았다. summary 실측 32×32px. `/complexes`는 같은 도형 설명을 팝오버와 차트 아래 `.note`에서 중복한다. `/trades`도 막대/선·띠 해설을 상시 본문에 둔다.
- 변경: 새 라이브러리 없이 기존 패턴을 전 페이지에 사용. 아이콘 glyph는 16px를 유지해도 클릭/탭 영역은 44px로 넓힌다. hover뿐 아니라 탭·Enter/Space로 열리고 Escape/바깥 클릭으로 닫히는 동작과 모바일 화면 안 배치를 검증한다. 현재 열기/닫기와 포커스 동작을 접근성 통과로 주장하지 않는다.
- 표면: 축 단위, 범례, 기준일, 잠정치·적은 표본·샘플 같은 판단 필수 경고. 팝오버: `점=거래, 선=중간값` 설명, 25~75% 정의, 수급 기준 100의 세부 해설. 삭제: 범례와 같은 내용을 다시 나열한 하단 장문.
- before → after: `점: 개별 실거래 · 선: 월별 중위가 · …` → 범례에서 점/선 모양을 보여 주고 정보 버튼 안 `각 점은 거래 1건, 선은 월별 중간값입니다.`. 대출 기준과 같은 판단에 필요한 조건은 아이콘 안으로 전부 숨기지 않는다.
