## 위험과 후속 순서

1. MOLIT 어댑터는 실제 DTO·단위·페이지 동작 검증 전 운영 사용 금지. R-ONE도 행 단위 DTO·단위 및 부분 지역 결과의 완전성을 추가 검증해야 한다. 현재 성공 0행 R-ONE은 기존 자료를 유지한다.
2. 리포트 패키지 및 합성 데이터 차단을 구현하기 전 기존 수동 이동으로 공개해서는 안 된다. 기존 보고서가 최신 자산을 참조하는지 별도 감사해야 한다.
3. 개인 도구는 승인·정책 적격성을 판정하지 않으며 가격 하락과 소득 감소 시나리오가 없다. 입력이 기기에서 전송되지 않는다는 경계는 브라우저 네트워크 계측으로 재확인해야 한다.
4. 대표 그래픽, 모든 I01–I28의 단계별 데이터 계약, 실제 샘플 표시, 접근성·CLS 검증을 후속 구현한다.
