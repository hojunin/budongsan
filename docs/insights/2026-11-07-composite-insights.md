## 공통 계산·노출 규칙

- E=기존 원천 필드로 설계 가능. **현재 구현/검증 완료 아님.** 현재 수집기의 실패/누락 위험을 보완하고 범위 완결·원본 유효값 게이트를 통과해야 한다. N=신규 소스 명세·응답·사용권·커버리지 검증 뒤 가능.
- T는 공동 관측 가능한 최근 완료월/분기다. 가격/거래는 기본 최근 완료3개월과 전년 같은3개월을 비교한다. 계절 조정값이 없으면 ‘계절조정 안 됨’을 표시한다. 단지 분포 기본6개월, 표본 기준은 공통 계약 적용.
- 매매 가격·거래수는 해제 제외를 기본으로 한다. 직거래 포함 여부를 고정해 명시한다. 분모가 다른 지표를 같은 ‘거래수’로 묶지 않는다.
- 금액은 만 원, 비율은 내부 fraction, % 변화와 %p 차이를 구분한다. 중간 계산은 반올림하지 않는다. 고정 집단/면적 기준이 없으면 집단 구성 차이의 가능성을 남긴다.
- `관측`: 데이터로 직접 계산한 사실. `시나리오`: 사용자 가정의 산술 결과. `해석`: 검토자가 쓴 문장. 이 세 유형을 필드와 화면에서 구분한다.
- 출처별 release_manifest, 공간/주택유형/기간/표본/사용권을 통과하지 못하면 `blocked`와 이유를 반환한다. 막힌 인사이트를 자극적 일반론으로 대체하지 않는다.
- 임계값/최소 표본은 초기 제품 정책이며 유의성 보장이 아니다. 검증 전 알림/추천의 정확도나 투자 성과를 약속하지 않는다.

## E — 기존 원천을 활용할 14개 정의

### I01. 가격과 거래량의 동행·엇갈림

- **질문/결합:** 특정 지역·면적대의 유효 거래 n과 ㎡당 중간 거래가격 M을 같은 두 기간에서 비교한다.
- **계산:** `price_chg=M_T/M_B-1`, `volume_chg=n_T/n_B-1`, 함께 IQR을 표시. 기본 전년동기3개월 비교, 두 기간 n≥30. 시장 전체 평가지수가 아님.
- **문장:** `{지역} {면적대} 거래는 {x}% {증감}, ㎡당 중간 거래가격은 {y}% {증감}했습니다.` 가격상승+거래감소를 ‘매수세 강함’으로 자동 번역하지 않는다.
- **그래픽/행동:** 4분면에 사용자 선택 지역만 강조하고 오른쪽에 실제 n·기간·분포. 단지 구성 확인으로 연결.
- **차단/한계:** 전기0건이면 비율 대신 건수 차이. 지역 변경/미완료월/표본 부족 차단. 중간값 변화는 같은 집의 가치 변화가 아니다.

### I02. 원 중간값과 고정 비교군 변화의 차이

- **질문/결합:** 전체와 같은 비교군 안의 관측 변화를 나란히 확인한다. 구성효과의 인과적 크기를 추정하는 것은 아니다.
- **계산:** 단지 식별자가 확정된 `단지×면적군` 중 양기간 n≥5인 공통 집단 g만 사용. `d_g=ln(median(ppm2)_T,g/median(ppm2)_B,g)`, 고정 기준기간 가중치 `w_g=n_B,g/Σn_B,g`; `matched_change=exp(Σw_g*d_g)-1`. 전체 원 중간값 변화와 나란히 제시한다.
- **커버리지:** 공통집단 거래가 양기간 전체 유효 거래의 각각70% 이상, 공통집단≥5, 전체 각기간 n≥30을 초기 게이트로 제안. 매칭률과 집단수 표시. 각 집단 n5도 충분성 보장은 아님.
- **문장:** `전체 중간가격 변화 {x}%, 공통 단지·면적군의 고정가중 변화 {y}%였습니다. 공통군은 거래의 {범위}%입니다.`
- **그래픽/한계:** 두 점/변화량과 매칭 커버리지. 두 값의 차이를 ‘구성효과가 정확히 z%를 설명’한다고 부르지 않는다. 반복매매지수나 인과 분해가 아니며 층·동·상태가 다를 수 있다. 단지명 유사매칭/과도한 표본 이탈은 차단.

### I03. 중간가격과 가격 분산

- **계산:** I01의 같은 기간/조건에서 `spread=(Q75(ppm2)-Q25(ppm2))/median(ppm2)`. M과 spread의 전년동기 차이, n을 함께 표시. 각기간 n≥30.
- **문장:** `중간 거래가격은 {x}% 변했고, 거래 가운데50%의 상대 구간 폭은 {a}에서 {b}로 변했습니다.`
- **그래픽:** 동일 축의 두 분포 띠, 실제 Q25/M/Q75와 n. ‘격차 확대’는 거래표본의 분산으로 한정.
- **차단/한계:** M≤0·분위수 이상 차단. 가격 구성·면적·단지 질의 혼합도 넓은 구간의 원인일 수 있다. 매도자 협상력·불평등·위험 점수로 해석하지 않는다.

### I04. ‘최근5년 최고가’ 경신의 확산 범위

- **계산:** 각 거래 d에 대해 계약일 이전60개월의 같은 확정단지/면적군 유효 거래가3건 이상 있는 경우만 평가. `is_record=price_d>max(past_prices)`. 동률은 경신 아님. `rate=record_count/eligible_count`, 전체유효 거래수 대비 eligible 비율도 표시. 대상 기간 eligible≥30 및 **각 거래가 필요로 하는 직전60개월 범위의 합집합** partition 완료 필요.
- **문장:** `비교 이력이 있는 {n}건 중 {k}건이 직전5년 최고가를 넘었습니다. 전체 거래 중 비교 가능 비중 {c}%.`
- **그래픽:** 경신비중+분모와 대상 단지수. 넓은 지역의 일부 고가단지 쏠림을 거래수와 단지수로 구분.
- **차단/한계:** 기존 브라우저용 `new_high` 플래그를 그대로 재사용하지 않는다(로더 기간 내 최고가일 수 있음). 당일 거래 순서는 임의로 경신이력을 만들지 않고 이전 날짜까지만 비교. 동일 면적군 총액 경신이며 동일 전용면적/같은 집의 최고가로 명명하지 않는다. 층/동/인테리어가 달라 동일 집 상승으로 해석 금지.

### I05. 같은 단지의 면적 선택 비용

- **계산:** 같은 단지·완료6개월의 59/84㎡대별 거래가 중간값과 ㎡당 중간값, 면적 실제 범위, n. 각군 n≥5, n5–19 주의. `추가 거래금액=M_84-M_59`, `단가 차이=U_84/U_59-1`.
- **문장:** `{단지} 두 면적대의 중간 거래가격 차이는 {금액}, ㎡당 중간가격 차이는 {x}%입니다.`
- **그래픽:** 두 점/연결선과 집값상한, 면적·기간·n 직접 라벨. 거래 보기로 이동.
- **차단/한계:** 넓은 면적 band의 실제 분포를 표시, 단지명/주소 중복 해소. ‘이 돈이면 업그레이드 가능’ 단정 금지. 다른 층·동 구성과 현재 매물 여부는 알 수 없다.

### I06. 매매·전세의 집단 가격 관계

- **계산:** 같은 단지·면적군·완료6개월의 유효 매매중간값 S와 유효 전세보증금 중간값 J. `group_ratio=J/S`, `group_gap=S-J`. 양쪽 n≥5, 각각 날짜·n 표시.
- **문장:** `{조건} 매매 중간값 {S}, 전세보증금 중간값 {J}; 두 거래집단의 비율 {r}%, 차이 {gap}.`
- **그래픽:** 양쪽 가격점과 비교조건·표본, 시점 차이가 있으면 명시. 보증금 비교와 자금 계산으로 이동.
- **차단/한계:** 현재 임대 원값의 월세 누락→0 변환을 거친 ‘전세’는 그대로 신뢰하지 않고 원본 monthlyRent가 명시적0인지 검증. 전세가율은 특정 호의 보증 안전성·매수 필요현금·회수가능액이 아니다. 양집단 층/계약구성 차이가 크면 비교 주의 또는 차단.

### I07. 고정 보증금 구간 안의 월세·보증금 변화

- **계산:** 동일 단지/면적군의 두 완료기간에서 기준기간에 고정한 보증금 구간별 월세 중간값·건수·구성비를 비교한다. 구간 경계는 원값 만 원으로 저장하고 비교 중 재산정하지 않는다. 각 단지/면적/보증금 구간의 비교 셀은 양기간 각각 n≥30. 각 셀의 보증금 중간값/Q25/Q75와 월세 중간값·구성비를 함께 표시한다. 전체 월세 중간값도 별개로 표시한다.
- **문장:** `전체 월세 중간값 변화 {x}%, 보증금 {범위} 거래군의 변화 {y}%; 해당 구간 비중 {a}%→{b}%.`
- **그래픽:** 보증금 구간별 작은 차트+구성비. 단순 전체 중간값만으로 ‘임대료 인상’을 단정하지 않음.
- **차단/한계:** 0원 월세/전세는 분리. 구간 경계가 같아도 실제 보증금은 다를 수 있어 보증금 자체가 고정됐다고 표현하지 않는다. 구간 내 보증금 분포가 달라졌으면 해당 이동을 명시하고 ‘같은 보증금에서 월세 인상’ 문장은 차단한다. 미상 월세·보증금·계약취소 검증 가능한 범위를 벗어나면 제외/주석. 신규/갱신 구분이 없으면 혼합을 명시하며 물가 임대료지수로 부르지 않는다.

### I08. 보증금 가정에 따른 환산 월비용

- **계산:** 사용자가 고른 실제 임대 거래2–3건(같은 지역·면적·기간)의 `D=보증금`, `R=실제 월세`; 사용자 가정 연비율 r로 `C=R+D*r/12`. 첫 줄에는 원래 D/실제 납부 R, 다음 줄에는 ‘가정 연 r%의 환산값 C’를 표시한다. C는 실제 납부액이나 현금지출액이 아니다. 기본값은 공식 금리라고 가장하지 않고 사용자가 입력한 가정이다. 초기 r은 명시 입력 전 결과를 비우거나 명시 예시 모드로 둔다.
- **문장:** `가정 연 {r}%에서 A의 환산 월비용 {C_A}, B {C_B}. 실제 납부 월세는 각각 {R_A}/{R_B}.`
- **그래픽:** 비용 비교 행 먼저, 산점도는 펼침. 금리 변경 시 같은 계약의 계산값만 갱신, 자동 재정렬 금지.
- **차단/한계:** 음수 입력·단위 이상·누락 차단. 서로 다른 집이 동일품질이거나 보증금 전환 협상이 가능하다는 뜻 아님. 예금 수익/대출 비용/세금은 개인별 다르며 이 식은 단일 기회비용 가정이다. 보증 안전도 판정과 분리.

### I09. 집값 상한과 과거 거래 분포

- **계산:** `B=비교할 집값 상한`, 동일 후보단지/면적군·완료6개월 가격분포에 `k=Σ(price≤B)`, `share=k/n`, M/Q25/Q75/n 표시. 각 단지 n≥5.
- **문장:** `최근 {기간} 유효 거래 {n}건 중 {k}건이 설정한 집값상한 {B} 이하였습니다.`
- **그래픽:** 같은 축의 단지별 분포+상한선, 메타에 면적·연식·마지막 거래월. 상한 범위 밖 표시. 거래 보기/내 자금으로 계산 연결.
- **차단/한계:** ‘내 예산’ 대신 집값상한, 현금/대출과 구분. 과거 거래 비중은 현재 구매 가능성/매물 수/체결확률이 아니다. 검색 지역의 거래가 덜 수집됐으면 차단.

### I10. 다른 시도 거주자의 매수 비중 vs 건수

- **계산:** 같은 R-ONE 거주지별 아파트 통계의 상호 배타 항목으로 `external=total-local_sgg-same_sido_other`, `share=external/total`. 최근 공통 완료3개월과 전년동기 합계 후 비중/건수/전체 변화를 계산. 하위항목 정의와 합계 정합 검증 필수.
- **문장:** `다른 시도 거주자의 매수 건수 {x}% {증감}, 전체 중 비중 {y}%→{z}%, 전체 건수 {n_B}→{n_T}.`
- **그래픽:** 건수와 비중 별도 작은 차트. 관할 시군구 밖/시도 밖은 따로 명명.
- **차단/한계:** total0·부분 항목·음수 잔차·중복 범주 차단. 외국/거주지 미상/기타 범주가 잔차에 포함되는지는 공식 분류로 확인하고 확인 전 외부 거주자로 분류하지 않는다. 전년 external=0이면 증감률 대신 건수차. 통계 건수는 국토부 계약일 건수와 집계 기준이 다르므로 분모 혼합 금지. 외부투기·실제이주·청년외지인 교집합으로 해석 금지.

### I11. 청년층 매수 비중 vs 건수

- **계산:** 같은 R-ONE 연령별 아파트 통계에서 `young=20대이하+30대`, `young_share=young/합계`. I10과 같은 기간 기준으로 청년층·전체 건수와 비중 변화를 표시. 다른 연령/합계를 다시 합산하지 않는다.
- **문장:** `20대 이하·30대 매수 건수 {x}% {증감}, 비중 {a}%→{b}%. 전체 건수 변화는 {y}%.`
- **그래픽:** 절대건수+비중을 나란히 두어 ‘전체가 더 크게 감소해서 비중 상승’도 읽히게 한다.
- **차단/한계:** 연령미상 처리·모수 정의 확인, total0/누락 차단. 전년 young=0이면 증감률 대신 건수차. 공개 제목은 ‘청년’ 단독 대신 실제 집계 연령을 표시한다. 연령별 거래는 자금출처·생애최초·다주택 여부를 말하지 않는다. 거주지 표와 개별거래 수준으로 join하지 않는다.

### I12. 공식 조사 지수와 거래 중간가격의 관측 차이

- **계산:** 같은 지역/아파트/월의 R-ONE 월 매매가격지수 전년동월 변화와 국토부 완료3개월 ㎡당 중간가격의 전년동기 변화를 **별개 관측**으로 배치. 기간이 다른 점을 직접 표시. 가능하면 I02 매칭표본 관측과 n을 보조로 둔다.
- **문장:** `{지수 기준월} 공식 월간 조사 지수 {x}%, {실제 시작월}–{실제 종료월} 실거래 중간가격 {y}% 변화. 대상·시점·방법이 다릅니다.`
- **그래픽:** 같은 시각적 무게의 별도 패널, 각각 실제 기간/단위/방법. 퍼센트 차이를 ‘통계오류’나 ‘시장선행’으로 이름 붙이지 않는다.
- **차단/한계:** 면적 필터가 있는 거래와 전체아파트 공식지수를 일치 표본처럼 표현하지 않는다. 행정경계/기준년도 단절, 지수0·이전값 누락·표본 부족 차단. 주간 수치를 월간 거래와 임의로 가장 가까이 붙이지 않음.

### I13. 직거래 포함 여부에 대한 통계 민감도

- **계산:** 같은 지역·면적·기간의 해제 제외 거래에서 전체 집단의 M_all/n_all과 명시적 직거래를 제외한 M_non_direct/n_non_direct, `difference=M_all/M_non_direct-1`, 직거래 명시 건수 표시. 양계산 n≥30. 미상 거래유형은 별도 n 표시. 현재 direct boolean에서 미상을 복원할 수 없으므로 raw dealingGbn을 명시 직거래/명시 중개/미상으로 다시 정규화한다.
- **문장:** `직거래 포함 시 중간가격 {a}, 제외 시 {b}; 명시적 직거래 {k}건, 유형미상 {u}건.`
- **그래픽:** 계산조건 토글과 두 수치 미리보기, 표본 변화 강조.
- **차단/한계:** 직거래=이상거래/허위 신고가 아니다. 유형미상 처리에 따라 범위가 달라짐을 명시. 작은 가격 차이를 범죄·시장 왜곡 주장으로 확장하지 않는다.

### I14. 인사이트를 해석할 수 있는 자료 범위

- **계산:** 사용자 조건에서 `완료 partition/예상 partition`, 관측 최종월·수집 cutoff·기간별 n·실패 목록을 함께 반환한다. 예측 partition 분모를 못 정하면 완결률을 숫자로 표시하지 않는다. 자료가0건인 성공 partition과 실패를 구분한다.
- **문장:** `매매는 {범위}까지, 전월세는 {범위}에서 확인했습니다. {누락} 때문에 {인사이트ID} 비교를 보류했습니다.`
- **그래픽:** 정상/누락/잠정/미수집의 작은 범위표와 각 결과 옆 짧은 상태. 별도의 장문 경고창으로 모든 화면을 밀지 않는다.
- **차단/한계:** 데이터 수가 많은 것을 정확도 점수로 표시하지 않는다. 현재 로그가 transport/페이지 완결성을 증명하지 못하는 범위는 ‘확인 필요’. 기술 운영 상태의 관측이며 시장 흐름 인사이트 수로 과장하지 않는다.

## N — 추가 데이터 뒤 제공할 6개 정의

### I15. 금리와 월 상환 현금흐름의 민감도

- **데이터/계산:** ECOS 검증된 주담대 신규취급 금리(개인금리 아님), 사용자 대출원금 L/기간 N, 기존 상환함수. 월비율 i=r/12, `payment=L*i/(1-(1+i)^(-N))`, r0이면 L/N. L/r은 유한 비음수, N은 양의 정수 개월, 원리금균등·고정금리 가정을 명시한다. 기준/±0.5%p/±1%p 중 유효한 비음수 시나리오.
- **문장/그래픽:** `동일 대출가정에서 금리 {a}%→{b}%일 때 월 상환액 차이 {x}.` 금리 곡선과 상환액, 원금/이자 내역. 개인의 실제 금리·원금·기간은 명시 입력.
- **차단/한계:** 신규취급 주담대 항목 코드/응답 단위 확정 전 차단. 기존 예산 함수의 검증·대출상품 가정 확인 필요. 월 상환액 전체는 비용이 아니라 원금상환 포함 현금흐름. 이것만으로 매수/임차 유불리 판단 금지.

### I16. 공급 단계와 임대시장의 병렬 변화

- **데이터/계산:** 같은 지역·주택유형의 착공/준공 월흐름12개월 합계 및 전년동기 변화(비교할 전체24개월 완료 필요), 같은 지역 아파트 임대 거래수/전세·보증금 고정군 월세 추이. 유형이 일치하지 않으면 ‘전체주택 공급/아파트 임대’로 별개 표기하고 수치 비율/동등조건 비교를 하지 않는다.
- **문장/그래픽:** `준공 실적 {x}% {증감}; 같은 지역 임대 거래 {y}% {증감}, {조건} 보증금/월세는 {z}.` 단계별 작은 막대와 임대 패널, 각 시점.
- **차단/한계:** 인허가/착공을 고정2–3년 시차로 입주 예측 변환하지 않는다. 준공은 실제 입주가 아니며 임대료 변화의 원인으로 단정하지 않는다. 유형/범위/12개월 누락 확인 필요.

### I17. 미분양 재고의 양·구성과 공급 실적

- **데이터/계산:** 월말 전체 미분양 U, 준공후 미분양 C, `completed_share=C/U`, U/C의 전년동월 차이, 같은 지역/주택유형의 최근12개월 준공 흐름을 별도 제시. U0이면 비중 null. U≥C≥0 검증.
- **문장/그래픽:** `미분양 {U}호 중 준공후 {C}호({s}%). 전년동월 재고 차이 {d}, 최근12개월 준공 {Q}호.` 한 시점의 구성막대(준공 전 U−C와 준공 후 C, 합계 U)+준공 별도 패널. U와C를 별개 누적 구간으로 더하지 않는다.
- **차단/한계:** U와C 중복 합산 금지(C는 U 일부), 기간 재고 합계 금지. 준공 수로 나눈 값을 검증 없이 판매소진기간이라 부르지 않는다. 재고 증감에 해소/재분류/신규공급이 함께 작용할 수 있다.

### I18. 인구·세대·이동과 임대 거래의 다른 움직임

- **데이터/계산:** 행안부 동일경계 주민등록 인구P/세대H의 전년동월 변화, KOSIS 같은 지역 12개월 순이동(전입-전출), 완료 임대 거래12개월 건수/가격. 전년대비 비교는 총24개월 완료를 요구한다. 각 통계의 공통 완료월과 실제 관측기간을 표시.
- **문장/그래픽:** `주민등록 인구 {x}%, 세대 {y}%, 순이동 {z}명; 아파트 임대 거래 {r}% 변화.` 지표별 작은 차트로 혼합 단위 분리.
- **차단/한계:** 주민등록 세대≠가구, 인구이동≠매수/임차 원인. 행정동/법정동 crosswalk/경계변경 미검증 시 차단. 출생/사망/세대분리 등으로 세대수와 인구는 다르게 움직이며 ‘실수요 증가’로 확정하지 않는다.

### I19. 청약 접수와 주변 기존 단지의 거래조건

- **데이터/계산:** 동일 공고·타입·공급구분의 접수 A와 모집 S로 `competition=A/S`, 공개 주택형별 분양최고금액 LTTOT_TOP_AMOUNT와 면적 증거, 선택한 주변 비교단지 실제 거래 범위/n/연식. F는 평균/대표 분양가가 아니라 공개 분양최고금액이다. SUPLY_AR는 공급면적이며 단위 미확인, HOUSE_TY 문자열에서 전용면적을 임의 추출하지 않는다. 검증된 공고문 전용면적 증거가 없으면 면적 일치·㎡당가격·차익 비교는 차단하고 서로 다른 조건의 원값을 별개 표시한다. 공급구분·지역우선/기타 항목 합산은 공식 규칙대로만. 반복되는 모집세대수를 중복 합산하지 않는다. 비교반경과 단지선정은 화면에 명시.
- **문장/그래픽:** `{공고/타입/구분} {S}호 모집에 {A}건 접수. 공개 분양최고금액 {F}, 선택한 기존 단지의 {면적/기간} 거래범위 {range}.` 경쟁률과 조건 비교표.
- **차단/한계:** 모집0/미발표·공고 정정 차단. 분양최고금액에 옵션·확장·중도금 비용이 미포함이면 표시. 분양가는 보통 주택형/층 조건이 달라 근처 중간값 차이를 ‘확정 차익’이라 부르지 않는다. API에 실제로 있는 필드만 사용한다.

### I20. 거래건수와 세대수 기준의 회전

- **데이터/계산:** 확정 매핑된 단지의 완료12개월 유효 거래 n과 같은 시점 K-apt 재고 세대 H, `turnover=n/H`, 거래 건수·H·연식 동시 표시. 단지 경계/단계/주소 변경 확인. 같은 매물 재거래도 거래건수로 센다.
- **문장/그래픽:** `최근12개월 {n}건, 공개 세대수 {H} 대비 {r}%.` 거래수×회전율 산점도와 연식/표본 직접 라벨.
- **차단/한계:** H0/시점불일치/단지 분할·통합/불확실 매핑 차단. 실거래 고유 가구의 이동률이 아님. 재거래로 100%를 넘을 수 있어 0–100% 안전게이지를 쓰지 않는다. 현재 세대수를 과거 시점으로 소급하지 않는다. K-apt 미포함 단지를 지역 집계에서 빼놓고 전체시장 회전율로 부르지 않는다.

## 3. 효과적으로 결합해 보여 주는 화면

모든 인사이트를 홈에 나열하지 않는다. 독자 질문에 맞는 3개 묶음에서 단계적으로 펼친다.

| 묶음 | 첫 화면 | 근거 펼침 | 다음 행동 |
|---|---|---|---|
| 매수 후보 | I09 집값상한 분포 + I05 면적 선택 + I01 지역 맥락 | I02 구성/I03 분산/I13 직거래 민감도 | 후보 유지, 거래 보기, 자금 가정 |
| 전월세 | I08 실제 납부·가정비용 + I06 집단 가격 관계 | I07 고정 구간 비교, 확보 후 I15 금리 | 계약 조건 비교, 원 거래 확인 |
| 주간/월간 브리핑 | I01 거래/가격 + I10/I11 매수 구성 + 확보 후 I17 공급재고 | I12 공식지수 차이, I16/I18 배경 | 관련 지역·단지·읽을거리 |

카드 구성은 질문 → 직접 계산한 사실2–3개 → 그래픽1개 → 비교조건/표본/기준일 → ‘다르게 볼 조건’이다. 해석은 사실과 분리해 작성자가 쓴다. 필터 변경은 관련 카드만 갱신하고 hover 없이 값 선택/해제·키보드 표로 읽을 수 있게 한다. 출처/단위/기간은 공유 이미지에도 포함한다.

**관측 조합 예시(수치 없는 템플릿):** ‘거래는 줄고 중간가격은 올랐습니다(I01). 공통 단지·면적군의 변화는 전체 중간값과 다릅니다(I02). 가격 구간 폭도 변했습니다(I03).’ 이후 ‘따라서 매수 적기’라고 자동 결론내리지 않고 단지 구성과 사용자 후보의 실제 거래로 연결한다.

시나리오 카드는 r·L·N 같은 사용자 입력을 공개 관측값과 시각적으로 구분한다. 모바일 카드 첫 화면은 질문·핵심 두 값·기간/n/잠정상태를 우선한다. 방법론은 펼치되 단위·핵심 한계는 숨기지 않는다. I01/I20은 텍스트 비교표를 기본 대안으로 제공하고 I03/I09의 축은 모바일에서도 공유한다. 예산선이 범위 밖이면 실제 금액과 방향을 표시하며 가장자리의 실제 선처럼 위장하지 않는다. I06 연결선에는 ‘집단 차이’, I16은 인과/동일 코호트 화살표 없이 독립 패널을 사용한다. 지역색은 고정, 선택강조는 외곽선/굵기, 상승/하락색은 의미값에만 적용한다. 회전율·전세가율을 녹색 안전등으로 바꾸지 않는다.

## 4. 검사받을 항목과 검증 단계

각 ID는 아래 항목별로 `설계 적합/조건부/보류` 판정한다. 설계 적합은 실데이터 검증 통과가 아니다.

1. 원천 필드와 실제 단위/범주가 존재하는가?
2. 공간·기간·주택유형·모집단이 결합 가능한가?
3. 분모0·결측·취소·중복·표본 이탈·보증금 조건이 처리되는가?
4. 계산이 설명한 관측/시나리오에 부합하며 인과·예측으로 확대하지 않는가?
5. 그래픽이 과거 거래를 현재 매물/안전성/확정 수익으로 오해시키지 않는가?
6. 한 소스가 실패하거나 정정됐을 때 과거 보고서와 새 출력이 일치하는가?

실행 순서: 명세검토 → 공개 가능한 합성 fixture의 계산/차단 테스트 → 승인된 원천 응답 fixture 검증 → 읽기전용 실제 스냅샷 대조 → 편집자 승인 → 모바일 사용자 과제. 이번에는 명세검토까지 수행한다. 실제 계산/시장수치 검증은 별도 단계로 남긴다.

단위 테스트 예: 분모0 시 null/blocked, 미수집 vs0건, 합계+하위범주 중복거부, 월세미상 전세분류 금지, 전년동기 누락 차단, 임계 표본 한쪽미달 차단, 금리0 월상환 L/N, 예산선 범위 밖, 고정구성 매칭률미달 차단, 과거 스냅샷 hash 불변. 제품 코드가 생길 때 이 정의로 테스트한다.

## 5. 사용자 핵심 가치 확장 — I21–I28

2026-11-07 추가 요구로 ‘지금 사도 되는가 / 가격은 더 오를까 / 참여자 심리 / 정책 반응’을 주 질문으로 확장했다. [추가 설계의 산식·출력·차단조건](../superpowers/specs/2026-11-07-buyer-decisions-sentiment-policy-design.md), [추가 원천 계약](../data/2026-11-07-candidate-interfaces.md#7-심리전망정책-반응-확장-소스)을 따른다. 앞의20개 판정은 최초 묶음에 대한 것이며 아래8개의 검사로 자동 승계하지 않는다.

| ID | 질문 | 결합과 표시 | 유형·준비 |
|---|---|---|---|
| I21 | 지금 매수해도 내 자금계획을 유지할 수 있나? | 거래후현금·월잔여·금리/소득 충격 비교 | 개인 가정 시나리오, 신규 입력·검증 필요 |
| I22 | 6·12개월 기다릴 때 필요한 현금은 어떻게 달라질까? | 임대/저축 현금흐름·미래 가격/금리 가정·향후 필요현금 | 시나리오, 완전 손익/기다리면 이익 판정 아님 |
| I23 | 상승 기대와 매수·거래 응답은 같은 방향인가? | 가격전망·수급·활발 응답·실제 거래를 독립 표시 | 관측, 신규 전망 항목 검증 전 해당 행 보류 |
| I24 | 지난 전망의 어떤 근거가 달라졌나? | 저장한 근거와 새 release의 동일 정의 관측 비교 | 관측/편집 재검토, 정정과 시장변화 분리 |
| I25 | 출처·응답대상별 시장 인식은 다른가? | 중개업소·공식 가구조사·매매/전세 시장부문 | 관측, 조사집단/문항/범위 확인 필요 |

| I27 | 정책 찬반·예상 영향·우려는 어떻게 다른가? | 외부조사·자발응답·편집견해를 별개 표본으로 표시 | 의견 관측/정성편집, 신규 수집·권리 검증 전 보류 |
